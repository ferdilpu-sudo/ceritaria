# Security Policy

Jangan membuka issue publik yang berisi credential, token, data pribadi, atau langkah eksploitasi terhadap deployment aktif.

Untuk deployment pribadi Ceritaria, laporkan temuan sensitif langsung kepada pemilik repository melalui kanal privat yang tersedia. Sertakan area terdampak, tingkat risiko, dan langkah reproduksi minimum yang aman.

Sebelum melaporkan bug sebagai security issue, lihat juga `docs/SECURITY.md` untuk boundary autentikasi, RLS, upload, embed, dan caching.
